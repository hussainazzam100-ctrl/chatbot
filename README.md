# 🦆 Quack.ai

A simple, duck-themed chatbot built with **HTML, CSS, and JavaScript**.

Quack.ai is a fun beginner-friendly chatbot that responds to greetings, shares interesting duck facts, and provides a small interactive chat experience — because apparently ducks needed their own AI.

## ✨ Features

* 🦆 Duck-themed chatbot interface
* 👋 Greeting responses
* 💡 Fun facts about ducks
* 💬 Interactive chat functionality
* 🎨 Custom HTML & CSS interface
* ⚡ JavaScript-powered responses
* 🖼️ Duck-themed images and visual assets
* 📱 Responsive design

## 🛠️ Built With

* **HTML5** — Structure and layout
* **CSS3** — Styling and interface
* **JavaScript** — Chat logic and user interaction

## 🧠 How It Works

Quack.ai uses JavaScript to process the user's message and determine an appropriate response.

The chatbot currently focuses on simple interactions such as:

* Greetings
* Duck-related questions
* Fun duck facts
* Basic conversational responses

The project is built with **vanilla JavaScript** to reinforce core JavaScript concepts and understand how chatbot logic works without relying on a framework.
